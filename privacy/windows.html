Privacy Policy (Microsoft Store)

Effective Date: 08/01/2026

This privacy policy describes how LOC & IVY LLC treats personal data for our applications available via the Microsoft Store for Windows devices.

1. Information Collected

Our Windows applications are designed to operate locally on your machine wherever possible. If an application requires internet access to function, any data transmitted will be secured and encrypted. We clearly prompt users for Windows capability permissions (e.g., webcam, microphone, location) as required by Microsoft Store Policies.

2. Diagnostics and Telemetry

We may receive anonymous crash reports and telemetry data provided by Microsoft’s developer tools. This data helps us diagnose bugs and improve app stability. It does not contain personally identifiable information.

3. Data Security

We implement commercially reasonable security measures to protect your information against unauthorized access, alteration, or destruction.
